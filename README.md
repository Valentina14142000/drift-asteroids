# Drift – AI Asteroids

Browser asteroids game with two AI systems:

- **Autopilot** (press `A`): predicts closest approach to every rock, flees the worst threat and shoots with lead aiming.
- **Hunter drone**: predicts where you will be and fires there. Its aim sharpens every wave.

## Run locally
```bash
npx serve .
```
Then open the printed URL. Controls: arrows or WASD, Space to fire, A for autopilot.
